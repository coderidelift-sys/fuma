What is CORS?

Cross-Origin Resource Sharing (CORS) is a security feature implemented by web browsers that blocks requests from one domain to another unless the server explicitly allows it.

In your case:

  • Frontend: Running on http://127.0.0.1:3001
  • Backend API: Running on http://localhost:3002

Since these are different origins (different ports), CORS restrictions apply.

Quick Fix Solutions

1Express.js Backend

If you're using Express.js, add this to your server:

const cors = require('cors'); app.use(cors({ origin: [ 'http://localhost:3001', 'http://127.0.0.1:3001' ], credentials: true }));
2Manual Headers

Or add CORS headers manually:

app.use((req, res, next) => { res.header('Access-Control-Allow-Origin', 'http://127.0.0.1:3001'); res.header('Access-Control-Allow-Methods', 'GET, POST, PUT, DELETE, OPTIONS'); res.header('Access-Control-Allow-Headers', 'Content-Type, Authorization, Accept'); res.header('Access-Control-Allow-Credentials', 'true'); if (req.method === 'OPTIONS') { res.sendStatus(200); } else { next(); } });

Framework-Specific Solutions

Common Issues & Solutions

❌ Common Mistakes
  • Using origin: '*' with credentials: true
  • Not handling OPTIONS requests
  • Missing required headers in allowed list
  • Wrong origin format (http vs https)
✅ Best Practices
  • Specify exact origins instead of wildcards
  • Always handle preflight OPTIONS requests
  • Include all necessary headers
  • Use environment variables for origins

Still Having Issues?

If you're still experiencing CORS issues after following this guide:

  1. Check your browser's developer console for specific error messages
  2. Verify your backend server is running on the correct port
  3. Ensure the frontend and backend URLs match exactly
  4. Try restarting both frontend and backend servers
  5. Check if your hosting provider has additional CORS restrictions
Pro Tip: Use your browser's Network tab to inspect the actual requests being made and their responses.
